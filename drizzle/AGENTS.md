# SmallData legacy rules
- SmallData history (legado_*, 0112–0125; BI _data acerto|saida): sales value = cobrança do acerto (legado_acertos_consultora.fonte = 'cobranca', Vlr. Bruto na Data Cob.); a closed maleta without cobrança counts zero (sem_cobranca); BI totals (kpis, anos) include internal records like SmallData; rankings, jornada and alertas exclude them. No direct grants; staff reads via legado_pode_ver (never can_view_kits); BI only via legado_bi_*; open maletas without acerto have unknown sales (null); people only via legado_consultoras_cadastrar (service; skips CPF, legacy code and same-name matches); CSVs never in repo. Why: privacy, no duplicates, match the official SmallData collection report.
- SmallData settled-history reads count a settled kit even when its remessa is open; the free ranking defaults to settlement date, and the monthly company series includes internal records (unlike consultant BI). Why: match SmallData settlement timing without treating unsettled kits as sales.
- SmallData finance (0149): legado_cobrancas/legado_fiados/legado_pagamentos (T_GF_*; no personal data) come in through the history import (cobrancas.csv, fiados.csv, pagamentos.csv); consultora_financeiro_smalldata(party) feeds the cockpit SmallData tab (read-only, cob_pode or registry.finance.view, codes via legado_codigos_da_pessoa). cob_fiado_linhas stays immutable: cob_fiado_smalldata_conciliar (preview; Master applies) links planilha lines to SmallData fiados and resolves pendente lines by codcli into fiado_historico titles (competencia = today), recording party/title in legado_fiado_vinculo; undo by lote via cob_fiado_smalldata_desfazer. The cockpit fiado tab includes lines of parties merged into the person (party_e_unificadas) and resolved lines. Why: the cockpit must show the whole SmallData ledger without rewriting lastro or double-creating debt.
- RLS policies call has_capability(auth.uid(), ...) and colab_* scope only inside (SELECT ...) initplans; colab scope uses colab_*_ids() arrays, never per-row functions. Why: per-row calls timed out searches on parties (0152).

- SmallData maleta situation (0127): legado_maleta_status per remessa+codcli from maletas_status.csv; 'na rua' = no fechamento AND legado_maleta_situacoes.na_rua (Master edits names/rule via legado_maleta_situacao_definir); counts show consultoras first, maletas second.
- Party code (0129): legacy consultants use their SmallData number as parties.code via party_codigo_smalldata_adotar / party_codigos_smalldata_adotar (preview first); old code kept in party_codigo_historico and still searchable; representatives keep their code (public page); new parties keep LC-…; never link records by code.
- First montagem links (0136): legacy consultoras get representante/praça from their SmallData cadastro via consultoras_vinculo_smalldata (preview, Master apply, fills NULLs only, log consultoras_vinculo_log, undo by lote); representatives without CPF are linked by the Master via legado_representante_vincular. Scanner/conference piece type comes from the product category through variantes_tipo_peca (same legado_categoria_tipo map as montagem_metas_ciclo; fallback tipoPeca). Accepting a maleta reactivates an inactive consultora (never bloqueado/desligado); no new maleta for bloqueado/desligado. Why: carteira, metas and bipagem must agree.
