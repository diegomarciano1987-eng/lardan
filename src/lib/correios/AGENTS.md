# Correios (CWS) — etapa 1 (0228)
- Correios stage 1 uses server-only transport and authenticated Master diagnostics; no shipment, billing or operational mutations, credentials stay in secrets and provider authentication bodies never reach the browser. Why: safe contract verification before shipping stages.
- Server-only transport in api.server.ts: token via POST /token/v1/autentica/cartaopostagem (Basic usuario:codigo, body numero/contrato/dr), cached in memory until 5 min before expiry (API limits token calls to 3/s). Hosts: apihom (homologação, default) and api (produção) by CORREIOS_AMBIENTE. Credentials only in Lovable secrets (CORREIOS_USUARIO, CORREIOS_CODIGO_ACESSO, CORREIOS_CARTAO, CORREIOS_CONTRATO, CORREIOS_DR, CORREIOS_CEP_ORIGEM) — never in code or chat. Why: contract credentials.
- Etapa 1 is diagnosis only (Master): token, contract services, preço/prazo of the standard box (40×30×10 cm, 1 kg, formato 2) and rastro. Nothing is posted or billed. Service codes for PAC ida/reversa must come from the contract listing, not be hardcoded. Why: codes differ per contract.
- 0236 (maleta pelos Correios): contract confirmed in production on 05/11/2026 — PAC CONTRATO AG 03298 (ida), PAC REVERSO 03301 (volta), valor declarado PAC = adicional 064. These codes now live in SERVICO (api.server.ts) because they were read from this contract's listing. CORREIOS_AMBIENTE is trimmed and lowercased (a trailing space once sent production calls to homologação, 401). The CWS access code is shared with the agency's Meus Correios: regenerating it breaks their postings. Why: incidents of 05/11.
- Flow: correios_maleta_dados (session; rules and pendências) → correios_envio_abrir (service; one live envio per maleta+sentido, débito vencido blocks the ida unless a Master gives a reason) → API POST /prepostagem/v1/prepostagens → correios_envio_resultado → label via rotulo/assincrono/pdf + download, stored in private bucket "correios". Rastreio runs in the morning sync and on demand: correios_envio_rastro sets entregue and, on the ida, due_at = entrega + 30 days. Volta only with the maleta "encerrada" (pré-baixa conferida) or acerto conferido; "Mandar código no WhatsApp" starts the 5 days (limite_postagem); after that correios_painel lists it for collection. Why: Diego's rules of 05/11.
