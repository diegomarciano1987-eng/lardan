# Fiscal / Focus NFe rules
- Fiscal results (attempt/authorization/rejection/homologated cancellation): service_role only (db/pendentes/11). Authorization requires nfe_chave_valida with emitter CNPJ; model/series/number from key. Why: no manual authorization.
- fiscal_settings emission/provider/environment/emitter changes: Master only, provider+emitter+environment required before activation, disable before environment change, audit fiscal.configuracao_alterada. Why: controlled fiscal switch.
- fiscal_prontidao: counts only, no personal data. Why: privacy.
- Maleta remessa NF (0214): button on remessa page/Documentos emits via focusEmitirRemessaMaleta (Master or kit.manage via fiscal_focus_pode_maleta, checked with the user session; data/registration then run as service with the user as ator — 0250, Diego 06/11/2026; fiscal configuration stays Master only; cycle conferida/expedida/transito/recebida/operacao with consultora; items = latest composition at kit_preco recorded price); fiscal_focus_envio_maleta_registrar (service only, homologação only) locks the cycle, rejects changed consultora/composition version and a second live remessa (pendente/processando/autorizado) per cycle+ambiente (unique index); screen reads fiscal_focus_notas_maletas (no personal data, [] without 'ver'). Why: one note per conferred kit, never stale pieces.
- Production (0216): ambiente comes only from fiscal_focus_ambiente(cycle) — homologação unless Master turned production on via fiscal_producao_definir (typed 'LIGAR PRODUCAO', piloto kit or todas; server checks FOCUS_TOKEN_PRODUCAO); with production on, a non-pilot cycle is refused (never silently test). Emission core lives in src/lib/focus/emissao.server.ts (button = Master session, queue = service). A production note authorized outside fiscal_settings.serie_producao ('3') turns emission and automático off (trigger fiscal_focus_serie_guarda, audit fiscal.serie_divergente). Copies XML/DANFE to fiscal_settings.email_copia_xml via Focus /nfe/{ref}/email, tracked by email_enviado_em. fiscal_fila (trigger on kit_cycles: conferida→remessa, encerrada→acerto only with production remessa) is drained by /api/public/fiscal/processar every minute. Item code = peca_referencia_etiqueta → barcode → SKU (fiscal_peca_codigo); IBGE falls back to ibge_municipios by city. Why: real notes only by explicit Master action, wrong series stops everything.
- Acerto NFs (0215): only for cycle 'encerrada' with authorized remessa of the SAME cycle; quantities from kit_balances (returned→devolução, sold→venda, lost→perda) mapped to remessa items via fiscal_focus_envios.itens_variantes (fallback: current code), each capped by remitted qty, leftover reported as sem_nota; unit value = remessa unit (×3 as retail); venda cites remessa only in informações complementares (contador 05/11/2026); one live note per cycle+ambiente+operação. Why: fiscal close of every consigned piece.
- Focus NFe (0118): homologação only; fiscal_focus_* writes are service_role (server fns check fiscal_focus_pode first); payload from src/lib/focus/nfe.ts roteiro (5917/1918/5114/5927, CSOSN 102, 1/3 retail) — never change roteiro to dodge a SEFAZ rejection; tokens/secrets only in Lovable secrets. Why: fiscal safety.
- DANFE enxuto (0224): DANFE is rendered by src/lib/danfe-compacto.ts from the AUTHORIZED XML (focusDanfeXml; one row per item, CODE-128C key barcode, SEM VALOR FISCAL watermark in homologação, CANCELADA when cancelled), because Focus' layout prints the RTC (IBS/CBS/IS) block per item (65 items = 5 pages). Kit managers may print the DANFE of a maleta note (fiscal_focus_pode_danfe) and see fiscal_focus_notas_maletas. Never change the XML/roteiro to shrink the DANFE. Why: maleta of 70 pieces must fit ~2 pages.
- Ambiguous Focus failure (network, 30 s timeout, 5xx) never becomes erro_envio blindly (0275): emitirNfe consults the SAME ref (404 → erro_envio, found → real status, no answer → processando_autorizacao = live note); /api/public/fiscal/processar reconsults pendente/processando refs older than 3 min (fiscal_focus_pendentes_conferir/fiscal_focus_conferida) and fiscal_fila_proximos leases items for 5 min. Why: production is on; a retry with a new ref would issue a second real NF-e for the same maleta.
