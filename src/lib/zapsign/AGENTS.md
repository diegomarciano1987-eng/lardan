# Assinatura digital (ZapSign) — 0224
- Contrato (per consultora) and promissória (per maleta) are created from assinatura_modelos (markdown with {{campos}}, Master edits via assinatura_modelo_salvar; seeded contrato is a DRAFT for legal review) through POST /api/v1/docs (markdown_text), signer link sent by WhatsApp (send_automatic_whatsapp) and copyable. Why: no PDF generation, consultant signs on the phone.
- Who: assinatura_pode = staff (master/diretoria/financeiro/kit.manage) or the consultant's own representante (rep_portal_pode + consultant_profiles.representative_party_id). Registration/return/reading are service-only (assinatura_registrar/retorno/pendente/ler). One pending per (party, tipo, cycle); resend cancels the previous one (substitui). Why: no duplicate documents, privacy.
- Webhook /api/public/zapsign/webhook?chave=ZAPSIGN_WEBHOOK_SECRET never trusts the payload: it re-reads the document from the API (detalharDocumento) before assinatura_retorno; signed never regresses. Signed file links expire in 60 min: zapsignArquivo fetches a fresh one. Secrets: ZAPSIGN_API_TOKEN, ZAPSIGN_AMBIENTE (producao|sandbox), ZAPSIGN_WEBHOOK_SECRET — never in code or chat. Why: provider security and legal record.
